# Queue administration #163 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port all 14 upstream queue admin APIs and the public QueueStats channel through ordinary BullMQ, HTTP and WebSocket paths.

**Architecture:** Queue use cases own current moderator/scope authorization and source-compatible operation boundaries. HTTP-only queue adapters manage all ten static queue names, while existing typed producers and business workers remain unchanged. One HTTP process owns QueueEvents, the 10-second statistics observation and its bounded memory history; its lifetime drains accepted work before closing queue and shared connections.

**Tech Stack:** Hono, TypeORM, BullMQ 6.3.11, ioredis, ws, Vitest; no new dependencies or schema.

**Spec:** [GOALS](../../backend-next/GOALS.md), [ROADMAP](../../backend-next/ROADMAP.md), [posting contract](../../backend-next/posting-contract.md), [#163](https://github.com/tiramiss-community/tiramiss/issues/163), parent [#124](https://github.com/tiramiss-community/tiramiss/issues/124). Compatibility source: Misskey `8e07cf085adf7009583d234a208e30436f020e26`; the stage-1 source oracle under `../compatibility/queue-admin/` supplies exact observed behavior.

## Review Focus

- Wrong queue/prefix/job ID must not cross into another queue; compare source missing-job and Redis-failure behavior.
- Moderator with wrong scope and expired/revoked role must fail before queue operations; write operations require moderator rather than administrator.
- Detached control/audit failure must preserve source HTTP acknowledgment while producing diagnostics and completing drain before connections close.
- Anonymous QueueStats subscription and requestLog length edges must match source without granting admin queue access.
- Startup failure, QueueEvents loss and SIGTERM with an in-flight operation must release owned handles/listeners/timers and preserve existing stream delivery.

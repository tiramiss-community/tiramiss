# Remote posting mentions (#195) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace posting's remote-mention 501 and stale-refresh omission with source-backed acquisition, core persistence, signer discovery and actual AP delivery.

**Architecture:** Federation owns plain-data acquisition/actor operations; the posting UseCase owns orchestration and actor creation transactions before Note persistence. Normal application composition supplies transport, keys, persistence and lifetime management.

**Spec:** [federation-base-contract.md](../../backend-next/federation-base-contract.md), [posting-contract.md](../../backend-next/posting-contract.md), [#195](https://github.com/tiramiss-community/tiramiss/issues/195); read root/package AGENTS, GOALS and ROADMAP.

**Goal:** Deliver public Create/Announce activities to existing accepted relays, using the posting author’s RsaSignature2017 signature and the existing deliver Worker.

**Architecture:** Add a cached accepted-relay reader, an outbound JSON-LD signer, and a relay producer behind plain federation ports. Relay delivery signs a separate activity copy once and submits each relay through `queue.add`, independently of followers/direct delivery. Keep both branches inside existing post-save draining and failure handling.

## Review Focus

1. **False cryptographic confidence:** C9 placeholders cannot prove LD validity. Require independent verification and deterministic fixed-upstream vectors — Task 1.
2. **Shared mutable activity or overlapping inboxes:** Ordinary delivery must remain unsigned; relay delivery must remain a separate job even for the same URL — Tasks 2–3.
3. **Partial producer failure:** A failed branch or relay submission must not suppress other attempts or escape post-save handling — Tasks 2–3.
4. **Cache boundary and failed reads:** Empty results cache; exactly `600000` ms remains valid; failed reads do not cache — Task 2.
5. **Shutdown during relay preparation:** HTTP success must precede completion, while graceful shutdown waits for accepted post-save work — Task 3.

## Decisions Fixed by This Plan

- Use only the three bundled contexts for outbound signing; reject unknown context URLs without network access.
- Start relay delivery after existing rendering/direct-author lookups and before followers collection.
- Start branches and individual relay submissions independently; settle every promise. Rethrow the original error for one failure, or `AggregateError` for multiple failures.
- Producer failures reach existing `note-post-save.failed` handling. This deliberately observes work that upstream leaves unawaited; it does not introduce producer retries.
- Existing PKCS#1 key-upgrade DB writes remain best-effort and outside the draining guarantee.

No additional product-design approval is required. Deterministic upstream fixture values were captured and reproduced in Task 1.

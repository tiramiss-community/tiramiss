# Note Antenna Producer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** #174の通常投稿から、固定本家のアンテナ照合・Redis timeline追加・antenna stream publicationを接続し、全責任監査で検出したchannel/remote instance集計も接続する。

**Architecture:** 保存時の投稿・作者・補正後channelのplain snapshotを独立したpost-save処理へ渡す。取得済みアンテナ定義の照合を業務側、DB/Redis/cacheをadapter側へ分け、既存のtimeline writer・pubsub・診断・終了待機へ接続する。

**Spec:** [GOALS](../../backend-next/GOALS.md)、[ROADMAP](../../backend-next/ROADMAP.md)、[投稿の最小契約](../../backend-next/posting-contract.md)、[#174](https://github.com/tiramiss-community/tiramiss/issues/174)、親[#127](https://github.com/tiramiss-community/tiramiss/issues/127)、全体[#114](https://github.com/tiramiss-community/tiramiss/issues/114)。具体契約は固定本家 `8e07cf085adf7009583d234a208e30436f020e26` の `core/AntennaService.ts:47–220`、`NoteCreateService.ts:645–732,779–784`、`CacheService.ts:116–131,178–184`、`misc/cache.ts`、`misc/acct.ts`、`UtilityService.getFullApAccount`、`GlobalEventService.publishAntennaStream`。

## Review Focus

1. `src=home`は本家のTODOであり追加following gateを作らない。specifiedは自分またはvisibleUserIds、followersは自分でもfollowing cache取得を先に実行する。listは現在membership。ユーザー指定はAcct.parse→fullApAccount→小文字比較であり正規化・trimを足さない。
2. sensitiveは補正後の`note.channel?.isSensitive`、bot/localは保存時作者を使う。keywordはtext + newline + CWのOR-of-AND部分文字列、空文字だけ除去。除外keywordだけでもtext/CWともnullならfalse。expressionは無視し、withFileは存在する空配列だけ拒否する。
3. 最初のアンテナ一覧だけ`isActive=true`をDBから読む。internal created/updatedはinactiveでも追加/置換し、updatedで未登録IDも追加、deletedは同IDをすべて除去する。TTLによる再照会や投稿ごとのfresh DBへ置き換えない。initial-load中イベント・同時load・reconnectの実際の扱いをテストして差異があれば記録する。
4. 全アンテナのmatchを並行開始し、ひとつのfollowing/list照会失敗で全出力を中止する。TLのmax200とpublicationは照合成功後だけ開始する。非同期publication失敗でも残りアンテナとpipelineを開始し、同期準備例外では未送信pipelineを送らず開始済みの古いID更新だけdrainする。
5. publicationはpacked Noteでなくraw Note＋reply/renote＋channel。pack失敗でもantennaは開始する。削除はcached IDをpurgeせず、保存snapshotの遅延追加も維持する。following cacheは30分Redis/1分memory、`follow`だけ無効化、`unfollow`を独自に追加しない。

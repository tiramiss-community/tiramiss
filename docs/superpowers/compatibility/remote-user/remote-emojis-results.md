# Public remote actor emoji ingestion (#195)

The public `notes/create` mention caller now extracts actor Emoji tags, persists remote URLs in `emoji` and supplies the returned names to `User.emojis`. Create extracts after attachment/tag/collection/birthday/URL preflight and before its actor transaction. Refresh extracts immediately after actor validation, using the URI-entry User host. Canonical recovery retains the existing User names. Later actor/Note failure, rejected refresh URL and skipped deleted refresh do not roll back independently committed emoji writes.
